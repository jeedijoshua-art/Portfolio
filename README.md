- **Vanilla JavaScript** for interactive elements like the custom cursor and theme toggle.

## 🌟 Features

- ✨ **Custom Cursor & Interactions**: A smooth, trailing cursor effect built with pure JS.
- 🌓 **Theme Toggle**: Switch between dark and light modes seamlessly depending on your preference.
- 📱 **Responsive Design**: Everything scales nicely whether you're on a phone, tablet, or a huge monitor.
- 📄 **Web Resume**: Integrated, easily readable online CV highlighting my experience and tech stack.

## 💻 Running it locally

If you'd like to check out the code and run it on your machine, it's pretty straightforward:

1. **Clone this repository:**
   ```bash
   git clone <repository-url-here>
   cd portfolio-project
   ```

2. **Run it:**
   You can just double-click `index.html` to open it in your browser, or spin up a local server if you prefer:
   
   ```bash
   python3 -m http.server 8000
   ```

3. **View it:**
   Open `http://localhost:8000` in your browser.
