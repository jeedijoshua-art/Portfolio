# Portfolio Repository

Welcome to my personal portfolio repository! I'm Jeedijoshua, a Computer Science student based in Hyderabad, India, focused on building strong fundamentals in programming and problem-solving.

This repository contains the source code for my portfolio website, where I showcase my learning progress, projects, and my professional resume.

## 🛠️ Built With

I built this portfolio without any heavy frameworks to keep things fast, simple, and clean.

- **HTML5 & CSS3**: Structure and styling with custom variables and modern layouts.
- **Vanilla JavaScript**: Interactive elements like the custom cursor, animations, and theme toggler.
- **AOS (Animate on Scroll)**: Used for smooth, subtle scroll animations.
- **Vanilla Tilt**: Adds a clean 3D tilt effect for a lively interface.

## 🌟 Key Features

- **Custom Cursor Effects**: A fluid, trailing cursor interactive element built securely with pure JavaScript.
- **Dark/Light Theme Toggle**: Seamless interface switching according to user preference.
- **Responsive Design**: Designed to scale intuitively across all mobile devices, tablets, and desktop displays.
- **Glassmorphism Aesthetic**: Modern soft UI with frosted glass background blurs.
- **Integrated Web Resume**: An easily readable online digital CV highlighting my experience and complete tech stack.

## 💻 Running it Locally

If you'd like to check out the code and run it directly on your machine, it's very straightforward:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jeedijoshua/Portfolio.git
   cd Portfolio
   ```

2. **Run a local server** (Optional but recommended):
   ```bash
   python3 -m http.server 8000
   ```

3. **View the site:**
   Open `http://localhost:8000` in your browser. (Alternatively, you can just open `index.html` directly in your web browser).
